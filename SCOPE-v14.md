# Acceptance scope 14.0.0

186 lessons (174 retained + 12 new workflow bridges), 31 major labs, three articulated teaching scenes and three nine-stage project routes. Counts describe distinct scopes.

Pure tests cover 72 FK/IK round trips, gait/support geometry, actual software attachment/release, 2 m quadruped goals and five drone waypoints with faults. Native checks cover actual WebGL input, scene lifecycle, pause/reset/resume, profile separation and AES-GCM synthetic archives. An eight-hour active synthetic renderer test is a release gate, not a claim about hardware. Final release notes state its observed result.

No second physical PC, real robot, flight, USB/OTA, WSL/ROS installation or field dynamics acceptance. Weather/references and optional tools have separately declared network requirements. Developer logs, screenshots and learner data are excluded.


The 12 workflow14 lessons add bounded, unit-aware calculations and private learner model drafts. They do not train a model, calibrate a camera, compile automatically, or certify hardware. Original robotics13 lesson IDs remain stable. A complete font/resource folder is required for file previews; installed distributions include it. Cross-platform integrated learning is supplied by Desk 5; the independent MCU SDK remains the Windows distribution.
