赋形造物工作室学院 隐私与本地数据说明
适用应用版本 12.0 · 2026年11月6日
作者：理工阿白菌 / TechABJ　联系：zeruik@qq.com

一、默认离线与本地学员
不需要注册网络账号。课程、教学模型和软件工作区可离线使用，学习记录不自动
上传给作者，也不作为使用分析或广告数据发送。一个本地学员不等于在线账号。
新建或编辑学员时必填显示姓名与组别（机械、电控、编程、运营、其他）；
显示姓名不要求为法定姓名，也不用于实名核验。学号、专业、学院、学校、性别和
生日均可不填写，不影响课程。旧档案可继续学习，编辑资料时再补齐必填项。
应用不要求或保存头像。

二、保存哪些资料
学员资料包括编号、显示姓名、组别、主动填写的学号/专业/学院/学校/性别/生日、
学习时间、课程进度、笔记、任务证据、练习草稿、路线周次、答题与检查历史及
修改时间、语言和主题。虚拟文件练习的目录与文本作为当前学员的练习草稿保存；
这些操作不读取或修改电脑上的真实文件。
学习日历汇总已记录的阅读活动、答题提交和完成标记；新版按日阅读时间依据
前台课程页的活动记录，不为旧档案补造缺失日期的数据。正确率按每题最新结果
计算，完成勾选不计入成绩。时间与完成标记不是出勤、身份或掌握程度的认证。
自动保存、动效及部分设备选项独立于学员档案。答题修改后再次提交会产生新的
记录，保留前次尝试；编辑草稿通常更新当前草稿，而非记录每个按键。
请勿在普通笔记、终端或代码练习草稿中填写真实密码、访问令牌或他人隐私。

三、本机文件、自动保存和备份
客户端在本机保存资料，默认使用安装位置下的 Archives 目录；可以在安装向导中
选择其他可写位置，首页“应用与存档位置”可查看实际目录，但不提供应用内存档目录迁移。
个人学习数据库使用 Windows 账户相关保护，并保留上一份有效副本；它与用于换电脑
的 .zth 导出档案不同。不要仅复制内部数据库就认为已经完成跨电脑迁移。
Windows AppData 下固定 ZeroToHand Academy 目录的 Local State 还保存本机加密
所需的保护密钥，不是普通缓存；继续使用或恢复本机库时须保留。只复制 Archives
中的数据库不能保证失去该密钥后的恢复，重装系统和换电脑应先验证 .zth 导出可用。
浏览器免安装版使用当前站点的本地存储，与客户端、其他浏览器彼此独立。

默认开启自动保存。关闭后修改先留在内存，应手动保存或导出后再离开；写入失败
应按提示处理，不能把屏幕上的修改视为已经持久保存。保存目录所在磁盘、同步
工具、共享目录或备份软件可能另行复制文件，其访问规则由用户和相关服务控制。
安装目录若位于受限位置或外置盘，权限或磁盘移除可能影响保存。

更新由用户取得新的完整发行包后离线运行安装器，不在后台检查或下载更新。
升级前请为每个需要保留的本地学员分别导出完整个人 .zth；使用管理系统时另行
导出 .zthm。安装器会把原存档目录中存在的 learning-store.zthdb、
manager-store.zthdb 及各自的 .previous、.pending 共六种固定文件
另存到该目录的 UpgradeBackups/before-版本-时间戳/，不递归复制其他个人文件。
个人库受本机保护，管理库使用管理员口令加密。这些副本仍包含相应个人资料，
应限制访问，并纳入你的备份与删除管理。
更改存档目录需明确选择复制；目标已有库时停止，原库仍保留。较新版本的库或无法
识别的课程资料会阻断当前程序写入，不能依靠旧安装器和旧程序保证向后降级安全。

四、导出、分享和删除
原生档案统一为小写 .zth，使用用户设置的口令加密；导入先解密预览。
口令不保存，遗忘后不能由作者恢复。导出时有两种范围：
1. 完整个人档案：包含已填写的个人资料、答题历史、私人笔记、任务记录和草稿，
   用于个人备份与迁移。分享前请考虑接收人范围。
2. 仅学习进度与成绩：保留编号、显示姓名、组别、已填写的学号/专业/学院/学校、
   学习时间、完成记录、题目结果与选项、日历活动和界面语言/主题；不含性别、
   生日、笔记、代码草稿及任务正文。终端/C 练习的提交正文与反馈也会删减，
   保留结果和时间。它仍是个人资料，不是匿名文件。
两种范围均使用口令加密，文件后缀同为 .zth。仅进度档案不能恢复未分享的内容；
导入个人学习端只创建独立学员副本，不覆盖完整档案。其来源标记随后续备份保留；
在副本中新写的笔记可进入该副本的完整备份，但不会恢复原档案未分享的资料。
管理端只提取下文第八节所列字段。接收人知道口令后仍能解密你发送的原文件，
不能把管理界面的字段筛选视为原文件已被删减。旧 .zthprogress 可能不具备同样
的加密保护，导入后可重新导出为 .zth。
进度文档只汇总学习与练习记录，不放入预测、解释或代码草稿正文，但仍可能含
姓名与进度等个人信息；它不是资格证书，也不是匿名文件。

卸载默认保留存档、UpgradeBackups 升级备份、storage-location.json 位置配置和
旧 AppData 数据。位置配置可能透露用户自己选择的路径；旧 AppData 也可能含
迁移前原件或缓存。保留是为重装和恢复资料，不表示这些文件已经匿名或清除。
需要清除资料时，先导出所需学员及管理备份、确认可解密并关闭应用，再管理“应用与存档位置”
显示的确切存档目录和核实后的缓存位置；同时检查上一份副本、升级备份、导出档案、
下载文件及外部备份。不一键递归删除可能混有其他个人资料的目录。浏览器资料可在
浏览器中清理对应站点数据。卸载应用不应被当作个人资料已完全删除的证明。
作者无法远程读取、代为恢复或清除仅存在用户设备中的学习资料。

本应用不修改系统或用户环境变量，不向系统 PATH 写入内容。编译隔离的环境仅供
本次子进程使用，退出后无需还原；卸载不会用历史 PATH 快照覆盖其他软件或用户的
后续修改，也不会代为卸载外部 USB 驱动、Arduino IDE 或其他工具。

五、可选天气
天气默认关闭。点击“联网查找城市”会通过 HTTPS 将输入的城市名称发送给
Open-Meteo 的地理编码服务，即使尚未选择结果或启用天气。选择城市并启用后，
应用才通过 HTTPS 向 Open-Meteo 请求
天气；不调用浏览器定位、不读取 GPS，不自动推断用户精确位置。
Open-Meteo 将接收网络请求所必需的 IP 地址、请求时间、所选城市对应坐标和
常规请求信息。应用不向该服务提交学员姓名、生日、笔记、学习记录或代码凭据。
所选城市不一定是用户所在地，但 IP 与请求信息仍可能与用户网络环境相关。
启用状态和城市选项用于后续显示；关闭天气可停止后续天气请求，已发出的请求
不能从对方系统撤回。天气不影响离线课程，不应作为安全决策的唯一依据。
第三方的处理、保留和使用规则由其政策说明，本应用不保证其服务持续或准确。
服务与隐私条款：https://open-meteo.com/en/terms
服务范围：https://open-meteo.com/en/pricing
天气数据来源：Open-Meteo；按其 CC BY 4.0 数据许可署名使用。

六、OTA 教学与代码生成器
教学工作区使用虚拟设备和示例网络，不连接真实板卡或 Wi-Fi，不进行实际烧录。
只使用生成代码、尚未选择真实编译时，OTA 代码生成器在当前页面内存中处理
用户主动填写的配置；其中的
Wi-Fi 名称、密码及鉴权值不自动写入学习档案或本地自动保存数据库，也不发送
给作者或天气服务。页面关闭或刷新后需要重新填写；浏览器或系统自身行为不在
本应用控制范围内。

【重要】下载或复制的代码可能含明文 SSID、Wi-Fi 密码、OTA 口令、服务器地址。
文件保存在用户选择的下载位置；复制后还可能留在剪贴板及其历史中。下载不是
加密保存，请自己保管，公开分享或上传 GitHub 前移除真实凭据、改为占位配置。
明确选择桌面版真实 USB 编译时，代码会写入本机临时目录，工具链生成的固件
也可能含有明文凭据；成功后清理源码，固件以临时编号有效期为15分钟供本次
上传，上传成功、失败、主动放弃、
过期或正常退出时清理相应材料。系统崩溃或强制结束可能留下临时文件。代码与
固件不进入学习档案，也不向作者上传。选择当前检测到的串口并在原生提示中
确认后，才将固件写入开发板；这会改变设备上的程序，应先备份重要程序和配置。
生成代码不代表已经编译、烧录或验证成功；真实设备、网络与服务器的访问和
日志行为依实际代码及配置而定，和本地教学应用不是同一数据处理过程。

七、外部链接与联系
点击外部资料会打开相应站点，其服务可能获得 IP 等常规连接信息，按该站点
隐私规则处理。联系作者邮箱会由用户选用的邮件服务发送内容，属于主动通信；
无需附上学习档案、真实口令或整份存档目录，请只提供解决问题所需的信息。
本说明随功能更新可能调整；涉及新的可选联网功能，应先明确展示用途和选择。

八、离线进度管理（11.0 新增）
管理员只在学员主动提供 .zth 与解密口令后导入记录，不扫描其他电脑、不提供远程监视或联网账号。导入前展示学员和资料范围，导入不替换管理员自己的学习档案。管理库保留学员编号、显示姓名、组别、已填写的学号/专业/学院/学校、完成课程及时间、累计学习时间、答题选项和历次提交；不保留生日、性别、私人笔记或代码草稿，终端/C 练习的提交正文和反馈也删去。可按组别、学校及待复习状态筛选。学校等字段来自学员自行填写，不验证就读关系。原始完整 .zth 仍可能包含已排除的资料，学员分享时应知悉接收人可解密原文件。
管理库单独用管理员口令加密，客户端文件为所选存档目录中的 manager-store.zthdb，浏览器预览则保存密文到当前站点。口令不保存，忘记后作者无法恢复。便携备份为 .zthm；更换电脑前应主动导出并核验。桌面升级同时备份管理库及 previous/pending 文件，卸载默认保留。管理界面移除记录不会清除之前的文件副本、升级备份或外部导出；需要彻底删除时还应管理这些副本。CSV 是含姓名与进度的明文报告，导出前确认用途。
CSV 汇总含编号、显示姓名、组别、学校、课程数量、正确率、提交统计和学习时间；
不含逐题正文、生日、性别、笔记或口令。导出 CSV 不会为其加密。

English summary
Learning data stays on the device by default. Creating or editing a local profile
requires a display name and group; legal names are not required or verified. Student
ID, major, college, school, gender and birthday are optional. Existing profiles remain
readable. Virtual file exercises do not access real files. Calendar statistics use
recorded activity, attempts and completion dates, without inventing missing history.
Answer accuracy uses the latest attempt per question; self-marked completion adds
no score and is not attendance or identity verification.

Both full and progress-only .zth exports require a password. Full archives may
contain private notes, demographics and code drafts. Progress-only exports retain
identifiers, display names, groups, supplied student/school fields, progress, answers
and activity, while removing gender, birthdays, notes, code/drafts and task text.
Terminal/C submission text and feedback are removed. Progress-only imports create
separate learner copies and retain their partial-origin marker; they cannot recover
information that was never shared. Passwords are not retained or recoverable.

Offline management imports only voluntarily shared .zth submissions. Its separate
password-encrypted vault retains names, IDs, groups, supplied student/school fields,
progress and answer history, excluding demographics, private notes and code drafts;
terminal/C submission text is removed. Group and school filters use self-reported
values. Original full archives may still contain excluded fields. Export .zthm for
portable manager backups. CSV reports expose names, IDs, groups, supplied schools
and progress summaries in plaintext. Deleting records does not delete older copies.
There is no cloud synchronization or remote monitoring. Personal desktop databases
use Windows-related protection; management databases use the administrator password.
Uninstall retains archives, upgrade backups, location settings and old application
data by default. Neither installation nor removal changes system or user PATH.

City search sends the entered city name to Open-Meteo; enabled weather sends selected
coordinates and normal connection metadata. It does not use device geolocation or
send learner records. Generating code alone processes settings in page memory.
Explicit real compilation writes temporary source and firmware, which may contain
plaintext credentials. Normal completion, expiry or exit cleans relevant temporary
materials; a crash may leave files. Downloaded or copied code may also contain
credentials. Compilation does not prove successful flashing or hardware testing.


十、12.0 多赛道与课内项目 / Version 12 learning tracks and projects
赛道选择随个人完整档案保存，只改变课程推荐，不改变所属组别，不删除已有进度。机械与自主系统教学参数、草稿和作答保存在当前学员档案。
标注操作台只在页面内存中读取主动选择的 PNG/JPEG 图像，不自动上传。图片、框与多边形需单独导出标注项目 JSON；它们不包含在 .zth 个人档案或进度分享中。切换学员或退出前请先导出项目；下载的项目包含原图，分享前检查隐私与素材许可。
Fusion、SOLIDWORKS、秀米、Canva、视觉和机器人资料链接由用户主动打开，各站点按各自规则处理网络请求。学院不登录或远程控制这些服务。
The selected track is included in a full personal archive and does not change the profile group or remove progress. Teaching parameters, drafts and answers belong to the active learner. Annotation images and shapes are handled locally in memory and require a separate project JSON export; they are not included in .zth or progress sharing. Export before switching learners or quitting. An exported annotation project includes its source image. External reference sites are opened only on request and apply their own policies.
